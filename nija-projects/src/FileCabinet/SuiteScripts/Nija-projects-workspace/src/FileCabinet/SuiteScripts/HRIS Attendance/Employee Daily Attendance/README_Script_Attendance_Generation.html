NetSuite Script Record & Custom Records

This developer guide documents the custom record structures, script settings, and program logic used to initialize daily timesheets for payroll tracking.

NetSuite Script Record Settings

  • Script File: mr daily attendance daily schedueld.js
  • Script Type: Map/Reduce Script (SuiteScript 2.x)
  • Scheduled Execution: Automated monthly run.
  • API Modules Used: N/record, N/search, N/log, N/format, N/query, N/runtime

Target Custom Record Types

  • Parent Record Type: Employee Daily Attendance (customrecord_njt_emp_daily_attendance)
  • Child Record Type: Timesheet Entry (customrecord_njt_emp_daily_atten_ch)
  • Sublist Link Machine ID: recmachcustrecord_njt_emp_daily_parent

Logic & Code Snippets

1. Get Input Data Stage

Queries all active employees with hire dates prior to or during the run date to identify employees who need monthly attendance logs:

var sqlQuery =
    "SELECT id, hiredate FROM employee WHERE custentity_hris_empemploymentstatus=1 and isinactive='F' and hiredate <= '" +
    dateString +
    "' ";

var results = query.runSuiteQL({ query: sqlQuery }).asMappedResults();

2. Map Stage

Checks for an existing parent record using findExistingRecord(). If none exists, creates the monthly parent shell and appends child daily lines in a dynamic transaction loop:

// Create new Employee Daily Attendance parent container
var attendanceRecord = record.create({
    type: "customrecord_njt_emp_daily_attendance",
    isDynamic: true
});
attendanceRecord.setValue({ fieldId: "custrecord_njt_emp_atten_employee", value: employeeId });
attendanceRecord.setValue({ fieldId: "custrecord_njt_emp_atten_month", value: monthToCreate });
attendanceRecord.setValue({ fieldId: "custrecord_njt_emp_atten_year", value: yearId });

// Create child daily lines inside sublist
createSublistRecords(attendanceRecord, currentYear, monthToCreate, employeeId, hireDate);
var parentRecordId = attendanceRecord.save();

Child Sublist Field Mappings

The sublist generation helper (createSublistRecords) creates one line per day in the month, mapping the following fields:

Sublist Field ID Field Name (UI Label) Mapped Value / Default Value

custrecord_njt_emp_daily_enddate End Date Specific day date (parsed Date object).
