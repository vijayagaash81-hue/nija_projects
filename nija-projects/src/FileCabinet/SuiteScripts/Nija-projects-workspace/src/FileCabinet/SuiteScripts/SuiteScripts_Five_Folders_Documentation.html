SQL Subquery Architecture & Metrics Calculations

Custom Cost & Galvanizing SQL Subqueries

The report uses conditional subqueries to separate regular cost components from galvanizing costs based on overhead names and remarks: 

-- regular cost sum (excluding Galvanizing process type)
NVL((SELECT SUM(NVL(det.custrecord_njt_production_details_amount, 0)) 
     FROM customrecord_njt_prod_deta det 
     LEFT JOIN customrecord_njt_overhead oh ON det.custrecord_njt_po_overhead = oh.id 
     WHERE det.custrecord_njt_pro_2 = po.id 
       AND (oh.custrecord_njt_oh_proctype IS NULL OR UPPER(BUILTIN.DF(oh.custrecord_njt_oh_proctype)) NOT LIKE '%GALVANIS%')), 0) +
NVL((SELECT SUM(NVL(exp.custrecordexp_amount, 0)) 
     FROM customrecord_expense exp 
     WHERE exp.custrecord_work_order_parent = po.id 
       AND (exp.custrecord_exp_remarks IS NULL OR UPPER(exp.custrecord_exp_remarks) NOT LIKE '%GALVANIS%')), 0) AS cost

-- galvanizing cost sum
NVL((SELECT SUM(NVL(det.custrecord_njt_production_details_amount, 0)) 
     FROM customrecord_njt_prod_deta det 
     JOIN customrecord_njt_overhead oh ON det.custrecord_njt_po_overhead = oh.id 
     WHERE det.custrecord_njt_pro_2 = po.id AND UPPER(BUILTIN.DF(oh.custrecord_njt_oh_proctype)) LIKE '%GALVANIS%'), 0) +
NVL((SELECT SUM(NVL(exp.custrecordexp_amount, 0)) 
     FROM customrecord_expense exp 
     WHERE exp.custrecord_work_order_parent = po.id AND UPPER(exp.custrecord_exp_remarks) LIKE '%GALVANIS%'), 0) AS galvanizing
Profit Margin & Row Highlighting Rules
  • Profit Calculation: Profit = Exclusive VAT Amount - Cost - Galvanizing.
  • Margin: Margin = Profit / Exclusive VAT Amount.
  • Row Styling (Loss): Renders class .row-loss (soft red background) if Profit < 0.
  • Row Styling (High Profit): Renders class .row-high-profit (soft green background) if Margin >= 40%.

Stock Consolidation & Multi-Location Sourcing

Stock Query & Needed Quantity Formula

The script queries the inventoryBalance table for items with open material requests: 

SELECT ib.item AS item_id, ib.location AS location_id, loc.name AS location_name, SUM(ib.quantityonhand) AS qty_on_hand
FROM inventoryBalance ib
INNER JOIN location loc ON ib.location = loc.id
WHERE ib.item IN (...)
GROUP BY ib.item, ib.location, loc.name
HAVING SUM(ib.quantityonhand) > 0

Needed Qty Formula: Needed Qty = Math.max(0, Requested Qty - Location Qty on Hand).

Consolidated vs Detailed Sourcing Mode

The consolidated script groups lines by item:

  • Detailed Mode: Lists each open material request line with the quantity on hand at the requested location.
  • Consolidated Mode: Groups by item and calculates the total required quantity. It sums stock across all warehouses to calculate the net needed quantity. The "View Stock" button opens a modal showing the stock level breakdown at each location.

NOC Date Suffix Formatting & Sourcing

Date Suffix Formatter (st, nd, rd, th)

The script uses a helper function to format dates (e.g., "1st July 2026", "23rd June 2026"): 

function formatNocDate(dateObj) {
    if (!dateObj) return '';
    const day = dateObj.getDate();
    const monthNames = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];
    const month = monthNames[dateObj.getMonth()];
    const year = dateObj.getFullYear();

    let suffix = 'th';
    if (day === 1 || day === 21 || day === 31) suffix = 'st';
    else if (day === 2 || day === 22) suffix = 'nd';
    else if (day === 3 || day === 23) suffix = 'rd';

    return day + suffix + ' ' + month + ' ' + year;
}
Clean Subsidiary Name Hierarchy Mapping

NetSuite displays parent-child relationships in subsidiary names (e.g., "Parent Company : Child Subsidiary"). The script cleans this up to show only the child subsidiary name on the certificate: 

let subsidiaryFullText = objRec.getText({ fieldId: 'custrecord_noc_subsidiary' }) || '';
let cleanSubsidiary = subsidiaryFullText;
if (cleanSubsidiary.indexOf(':') > -1) {
    let parts = cleanSubsidiary.split(':');
    cleanSubsidiary = parts[parts.length - 1].trim();
}

Voucher Printing Sourcing & File Access Details

Cheque Copy File Permission Handling

The Suitelet updates the cheque copy image file in the file cabinet (ID custbody8) to be online (available without login). This ensures the NetSuite PDF engine can render the image: 

var chequeImageId = rec.getValue({ fieldId: 'custbody8' });
if (chequeImageId) {
    try {
        var imgFile = file.load({ id: chequeImageId });
        if (!imgFile.isOnline) {
            imgFile.isOnline = true;
            imgFile.save();
        }
    } catch (imgErr) {
        log.error('Error updating image permissions', imgErr.message);
    }
}
Applied Invoices Sourcing & Sublist Chunking

The script loops through applied transactions on the payment record's `apply` sublist. It determines the transaction type, loads the record, and extracts the transaction number and project code (cseg_njt_seg_proj).

In the template `pmt_vou.xml`, the applied lines list is chunked into groups of 5 to maintain a consistent table height and prevent pagination issues: 

<#list applyBatch as apply>
  <tr>
    <td align="center"><#if apply.refnum?? || apply.doc??>\\${apply_index + 1 + (applyBatch?index * 5)}</#if></td>
    <td>\\${apply.transactionnumber!""}</td>
    <td>\\${apply.cseg_njt_seg_proj!""}</td>
    <td>\\${apply.doc!""}</td>
    <td align="right"><#if apply.amount?has_content>\\${apply.amount?string("#,##0.00")}</#if></td>
  </tr>
</#list>
