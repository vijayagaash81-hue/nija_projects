Script: biometric to employee daily attendance (2).js

Integration Purpose & Scope

This script is a scheduled NetSuite Map/Reduce script used to create and update child records of employee attendance from raw biometric sync feeds.

  • Data Source: The Daily Attendance - Sync record is populated by an external HRMS application through a RESTlet interface.
  • Data Destination: The daily logs are compiled and written directly into the corresponding employee's monthly Time Sheet Entry records.
  • Monthly Parent Timesheets: Parent monthly timesheet records are pre-created for every employee by a separate monthly batch Map/Reduce script.

Script Stages & Execution Lifecycle

1. Get Input Data getInputData

Calculates the target date dynamically (Current Date in IST minus 1 day to fetch yesterday's raw data) and searches for unprocessed sync logs:

// 1. Calculate Yesterday's date in IST (UTC+5:30)
var currentDate = moment.utc();
var istDate = currentDate.add(5, "hours").add(30, "minutes");
var previousDate = istDate.subtract(1, "days").format("DD/MM/YYYY");

// 2. Search for biometric sync entries for the calculated date
var searchObj = search.create({
    type: "customrecord_njt_daily_attendance_bio",
    filters: [ ... ],
    columns: [ ... ]
});

2. Map Stage map

Processes each biometric log in parallel, parses input/output check-in timestamps, computes daily working hours using helper utility methods, and maps details to the target employee:

var formattedWorkHours = calculateWorkHours(minBioTime, maxBioTime);

3. Reduce Stage reduce

Aggregates the daily logs per employee, loads the employee's existing daily attendance child record, computes overtime, sets updated values, and flags processed raw entries as complete:

// 1. Load the corresponding employee daily attendance child record
var existingRecord = record.load({
    type: "customrecord_njt_emp_daily_atten_ch",
    id: recordId,
    isDynamic: true
});

// 2. Set check-in/out times, locations, and calculated work & OT hours
existingRecord.setValue({ fieldId: "custrecord_njt_emp_daily_in_time", value: minBioTime });
existingRecord.setValue({ fieldId: "custrecord_njt_emp_daily_out_time", value: maxBioTime });
existingRecord.setValue({ fieldId: "custrecord_hris_actual_woking_hours", value: workhoursdecimal });
existingRecord.setValue({ fieldId: "custrecord_njt_ot_hours", value: otHour });

var savedId = existingRecord.save();
