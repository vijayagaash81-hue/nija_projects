Integration: Daily manual timesheet consolidation process

Integration Elements

This document highlights how consolidation queries, sublist indexes, and the Map/Reduce serialization parameters are integrated across the Suitelet and Map/Reduce script.

1. Suitelet Script

  • File Name: hris_dailymanualtomonthly_process_sl.js
  • Script Type: NetSuite Suitelet
  • Duties: Consolidates daily attendance data, presents a checklist grid to payroll managers, parses submitted values, and launches the Map/Reduce script.

2. Map/Reduce Script

  • File Name: hris_dailytomonthlyattend_process_mrs.js
  • Script Type: NetSuite Map/Reduce Script
  • Duties: Processes the checked employee details in parallel and saves/overwrites the records directly.

Data Aggregation & Comp-Off Calculation

The Suitelet uses a SuiteQL query to aggregate daily attendance records from the customrecord_njt_emp_daily_atten_ch child lines table:

SUM(CASE WHEN NVL(emp.custrecord_njt_emp_daily_working_hours, 0) = 0 THEN 0 ELSE NVL(emp.custrecord_njt_ot_hours, 0) / emp.custrecord_njt_emp_daily_working_hours END) AS comp_off

Comp-off is calculated as daily OT hours divided by employee daily shift hours. Standard roundoff is computed at execution time in JS using Math.round(compOff).

Serialized Parameter Data Structure

When the manager submits the checked rows, the Suitelet extracts parameters from the sublist array and writes them as serialized JSON object parameters to the Map/Reduce task:

Object Key Sublist Array Index Target Record Field ID Description / Usage
empid columnArray[2] custrecord_hrms_month_empid Employee Internal ID.
noPresntId columnArray[7] custrecord_hrms_month_presentdays Sum of present days.
noAbsentId columnArray[8] custrecord_hrms_month_absentdays Sum of absent days.
norotId columnArray[9] custrecord_hrms_month_rothrs Total overtime hours.
compOff columnArray[12] custrecord_compoff_days Comp-off float value.
compOffRound columnArray[13] custrecord_compoff_days_round_off Comp-off rounded integer.
