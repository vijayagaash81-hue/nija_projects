TS-UE-01 beforeLoad Open an INACTIVE Employee record in VIEW mode; then try direct URL edit. In VIEW mode, Edit button is disabled. In EDIT mode, user error is thrown: User is inactive so you cannot edit...
TS-UE-02 beforeLoad Open Employee record in VIEW mode. Inspect Client Script attachment. form.clientScriptFileId attaches customscript_hris_empleave_cs in VIEW mode with 0 governance overhead.
TS-UE-03 beforeSubmit Create and Save a NEW Employee record (Form 167). custentity_hris_empcode is assigned next incremented 5-digit number (e.g. 00143). Unique ref record is updated.
TS-UE-04 afterSubmit Save a NEW Employee with Code 00143 & Legal Name John Doe. Creates customrecord_cseg_njt_seg_emp with Name 00143 - John Doe and updates custentity_hris_empsegment.
TS-UE-05 afterSubmit Save a NEW Employee with Employee Category specified. Triggers Scheduled Script customscript_hris_emp_leavecredit via N/task. Check Script Execution Log for Task ID.
TS-UE-06 afterSubmit Save Employee record. Check customrecord_hris_employeedatasourcing. Creates or updates child sourcing record mapping hiredate, designation, department, location, subsidiary, gender, category.
TS-UE-07 afterSubmit Check Inactive on Employee (isinactive = true) and Save. Syncs isinactive = true across 4 child custom records (Compensation Change, Leave Balance, Sourcing, Compensation) using record.submitFields.
TS-UE-08 afterSubmit Update Employee department, grade, bank details, passport/visa numbers and Save. Automatically syncs 30+ fields into customrecord_hris_employee_compen_change via record.submitFields (2 governance units).
TS-UE-09 afterSubmit Change Working Location (custentity_hris_empworkinglocation) and Save. Updates multi-select custentity_hris_empholidays with active holiday IDs from customrecord_hris_holiday_master via record.submitFields.
