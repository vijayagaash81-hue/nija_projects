1. Suitelet Customizations

hris_dailymanualtomonthly_process_sl.js

A. Added UI Columns in Sublist

Two new text fields were added to the employee monthly attendance sublist to display the calculated values dynamically to the users:

  • Comp Off (custpage_compoff): Displays the float comp-off calculation.
  • Comp Off Roundoff (custpage_compoffround): Displays standard rounded integer.
var compOffField = salesSublist.addField({
    id: "custpage_compoff",
    type: serverWidget.FieldType.TEXT,
    label: "Comp Off"
});
var compOffRoundField = salesSublist.addField({
    id: "custpage_compoffround",
    type: serverWidget.FieldType.TEXT,
    label: "Comp Off Roundoff"
});

B. SuiteQL SQL Query Mod

Both query definitions in setSublistvalue (with and without location parameter check) were modified to perform the division directly in the database while guarding against potential division by zero:

SUM(CASE WHEN NVL(emp.custrecord_njt_emp_daily_working_hours, 0) = 0 THEN 0 ELSE NVL(emp.custrecord_njt_ot_hours, 0) / emp.custrecord_njt_emp_daily_working_hours END) AS comp_off

Note on SQL spacing: Added explicit whitespace spacing before " GROUP BY " dynamically concatenated clauses to prevent SQL parsing syntax error (e.g. 1GROUP BY or 2GROUP BY).

C. Sublist Value Mapping & Rounding

Fetched comp_off from the result set, computed standard roundoff using Math.round(), and set these values to the corresponding sublist lines:

var compOff = rec.comp_off || 0;
var compOffRound = Math.round(compOff);

sublist.setSublistValue({
    id: "custpage_compoff",
    line: i,
    value: compOff.toFixed(2),
    ignoreFieldChange: true,
});
sublist.setSublistValue({
    id: "custpage_compoffround",
    line: i,
    value: compOffRound.toString(),
    ignoreFieldChange: true,
});

D. Sublist Column Index Realignment in POST

Since the weeklyOt and holidayOt fields were commented out in the sublist setup, all columns starting from index 9 shifted left by 2 positions. Realigned column mappings inside the POST handler:

  • selectObj.noweeklyId = ""; // Disabled/Commented out
  • selectObj.noholiId = ""; // Disabled/Commented out
  • selectObj.norotId = columnArray[9]; // maps to custpage_rothours
  • selectObj.intempId = columnArray[10]; // maps to custpage_de_empintid
  • selectObj.parId = columnArray[11]; // maps to custpage_parid
  • selectObj.compOff = columnArray[12]; // maps to custpage_compoff
  • selectObj.compOffRound = columnArray[13]; // maps to custpage_compoffround

2. Map/Reduce Customizations

A. Direct Field Value Update

In the Map/Reduce script, updated createMonthlyAttendanceRecord to map and directly store the parsed parameter values from the Suitelet into the custom fields on the custom Monthly Attendance record (customrecord_hrms_monthlyattendance):

  • Comp-Off Days: mapped to custom field custrecord_compoff_days
  • Comp-Off Days Round Off: mapped to custom field custrecord_compoff_days_round_off
var newCompOff = parseFloat(data.compOff || 0);
var newCompOffRound = parseFloat(data.compOffRound || 0);

monthlyAttendanceRecord.setValue({ fieldId: 'custrecord_compoff_days', value: newCompOff });
monthlyAttendanceRecord.setValue({ fieldId: 'custrecord_compoff_days_round_off', value: newCompOffRound });
