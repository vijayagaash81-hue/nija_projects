Biometric Attendance Sync to Timesheet Entry

Integration Workflow Documentation

System Architecture Overview

This Map/Reduce script is a key integration block that automates the synchronization of raw employee biometric logs into the primary Timesheet Entry database.

1
External HRMS App to NetSuite
The raw attendance data is captured via an external HRMS application and pushed into NetSuite's Daily Attendance - Sync (customrecord_njt_daily_attendance_bio) record through a RESTlet interface.
2
Schedule & Date Selection
The Map/Reduce script runs on a daily schedule. In the getInputData stage, it converts the current timestamp to Indian Standard Time (IST) and subtracts one day to calculate yesterday's date.
3
Timesheet Entry Integration
The script queries all unprocessed Daily Attendance - Sync records for that date and maps/updates the sync details to the employee's parent Time Sheet Entry record.

Note: The parent Time Sheet Entry records are generated on a monthly basis by a separate Map/Reduce script for every employee in NetSuite before this daily biometric sync takes place.
