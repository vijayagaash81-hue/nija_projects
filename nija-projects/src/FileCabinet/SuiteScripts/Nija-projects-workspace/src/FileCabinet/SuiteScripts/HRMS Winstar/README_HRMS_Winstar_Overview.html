HRMS Winstar Integration Suite

Detailed Functional Directory Reference

Winstar HRMS Module Framework

The HRMS Winstar directory houses the entire suite of payroll, leave, attendance, and employee self-service features. It is built as a modular integration engine connecting NetSuite ERP transactions to external employee web portals and mobile applications.

1. Mobile Sync & RESTlet API Engine

The HRMS API folder is the central communications node for the Winstar Mobile App. It publishes NetSuite master data endpoints and listens for mobile requests via RESTlets and scheduled batch processes:

Master Data Feeds (GET RESTlets) Pushes Department, Currency, Subsidiaries, Countries, Skill Masters, and Asset Master lists to the mobile terminal interface.
Employee Requests (POST RESTlets) Accepts employee requests from mobile (such as Leave Applications, Expense Claims, Document Uploads, Grievance reports, and Letter requests) and writes them to NetSuite.
Biometric Pushes Translates check-in/out timestamps from the mobile phone GPS checks to the biometric attendance record.
Authentication & Passwords Handles secure authentication tokens, mobile devices ID registration, and IMEI binding for employees.

2. Attendance Processing & Approvals

Handles daily biometric timesheet aggregation, monthly timesheet creation, roster assignments, and manager approval gates:

Monthly Attendance Creation Suitelet dashboards and Map/Reduce engines used to initialize monthly daily containers and compute employee shift configurations.
Monthly Attendance Approval Workspace tables and verification gates to review employee worked hours, OT limits, and LOP (Loss of Pay) deductions before releasing payments.

3. Salary Records & Revision History

Manages historical compensation logs, revisions, and pay structures for employees:

Salary Updation & Revision Stores client validations (CS) and server triggers (UE) verifying revisions, restricting unauthorized field updates, and tracking bulk pay group changes.
Salary Register Layouts Generates consolidated registers and journal files detailing payroll components for accounting audits.

4. Leave Operations

Provides workflows for managing leave types, running leave balances computations, and final settlements:

Leave Balances Tracks accruals, encashment details, and remaining leave balances per employee type.
Leave Settlement Computes final settlements (gratuity, notice period adjustments, and vacation payouts) for resigning or terminated employees.

5. Payslip Engine & Web Portal

Generates print-ready payslips and hosts web pages for employee self-service checkins:

Payslip PDF Generator Renders PDF layouts of monthly payslips dynamically from payroll records.
Web Portal & Forms Provides client UI screens for internal employee self-service web pages.
