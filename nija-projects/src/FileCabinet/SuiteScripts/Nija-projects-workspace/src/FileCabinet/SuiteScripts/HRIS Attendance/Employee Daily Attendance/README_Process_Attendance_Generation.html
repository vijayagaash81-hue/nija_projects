Monthly Attendance Records Generation

Business Process & Execution Flow

Process Overview

This scheduled Map/Reduce script runs on a monthly basis to pre-generate the structured attendance shells for all active employees. This ensures that daily check-in/out records can map onto a pre-existing timesheet hierarchy.

1
Employee Filtering

The script queries active employees from the database who were hired on or before the target payroll month.

2
Parent Record Creation ("Employee Daily Attendance")

For each matched employee, the script checks if a parent record already exists for the month. If not, it creates a new parent record container representing that month's attendance.

3
Child Lines Creation ("Timesheet Entry")

It loops through each day of that month (28, 29, 30, or 31 days) and appends a child line for each day, setting default status values, normal working hours, shift master rules, and lunch timings.

4
Roster, Leaves & Holidays Overrides

Applies approved configurations over the daily entries: sets weekly offs (duty rosters or standard shifts), marks public holidays, and applies pre-approved employee leaves directly to the child lines.

Benefits: Pre-populating monthly attendance containers dramatically improves daily restlet/biometric synchronization speed by ensuring daily sync tasks only need to query and update single child records rather than creating heavy transaction records in real-time.
