HRIS Attendance System

Complete Employee Attendance Processing Workflow

Process Architecture

The NetSuite HRIS Attendance system leverages a coordinated three-phase payroll lifecycle. This documentation outlines how the monthly parent shells are initialized, how daily biometric logs are synchronized, and how the monthly consolidation approvals operate.

1. Monthly Attendance Shells Initialization

This automated background process initializes the attendance records for all active employees on a monthly basis, preparing a month's worth of empty daily lines to prepare for daily logs mapping.

1
Active Employees Filter

The scheduler queries active employees from the system database who were hired on or before the target month.

2
Parent Record Creation ("Employee Daily Attendance")

Initializes a parent container record representing the payroll month for each filtered employee.

3
Daily Lines Generation ("Timesheet Entry")

Loops through every calendar day of the target month and appends a child row setting default shifts, lunch hours, and status properties.

4
Calendar Rules Application

Applies approved configurations over the pre-created daily lines, including weekly offs, public holidays, and pre-approved leaves.

2. Daily Biometric Attendance Synchronization

This daily scheduled batch process retrieves punch-in and punch-out check-in logs from external physical biometric readers and updates the NetSuite timesheet daily lines.

1
HRMS Application Integration

Raw employee biometric logs are captured by the external HRMS application and pushed into the NetSuite sync table via an API RESTlet.

2
Daily Schedule Execution

The synchronization script triggers on a daily schedule, converts UTC time to Indian Standard Time (IST), and calculates yesterday's target date.

3
Daily Records Update

Queries unprocessed sync logs, determines the first check-in and last check-out times, calculates working/overtime hours, and updates the corresponding timesheet line for the employee.

3. Consolidated Attendance Approval & Monthly Records

This phase is an interactive payroll workspace for administrators to consolidated daily entries, verify calculated overtime, and submit finalized payroll entries.

1
Manager Filters selection

Payroll managers filter the workspace selection by Month, Year, Subsidiary, and Location.

2
Consolidated Attendance Board Review

The dashboard renders a grid showing totals per employee: Present Days, Absent Days, Overtime Hours, Comp Off, and Comp Off Roundoff.

3
Payroll Submission and Batch Write

The manager checks the employees to process and submits the board. This launches a background Map/Reduce script which creates or updates the official **Monthly Attendance** records directly.

Comp-Off Rule: Comp-off values are calculated by dividing daily OT hours by daily shift hours, with standard integer rounding (e.g. 0.25 roundoff yields 0, whereas 0.50 roundoff yields 1).
